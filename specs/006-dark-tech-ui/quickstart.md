# Quickstart: 全站深色科技风 UI 改造验证指南

**Branch**: `006-dark-tech-ui`

## 前提条件

- 后端已启动（端口 8080）
- 数据库和 Redis 正常运行

## 启动前端开发服务器

```bash
cd plus-ui
npm run dev
```

访问 http://localhost

## 验证清单

### Phase 1 验证（P0 核心框架）

1. **打开登录页** — 确认深色渐变背景 + 网格纹理 + 玻璃拟态卡片
2. **登录系统** — 确认登录流程正常，无浅色闪烁
3. **检查侧边栏** — 确认深色背景、活跃菜单高亮 + 左侧发光指示条
4. **检查顶部栏** — 确认毛玻璃效果（内容区在顶部栏下方可见）
5. **检查页面背景** — 确认网格纹理和装饰光晕
6. **折叠/展开侧边栏** — 确认响应式正常，无样式错乱

### Phase 2 验证（P1 关键页面）

7. **打开首页** — 确认架构图在深色背景上清晰可见
8. **打开系统管理 > 用户管理** — 确认表格、搜索表单、对话框均深色适配
9. **打开系统管理 > 菜单管理** — 确认树形组件深色适配
10. **打开任意对话框** — 确认毛玻璃背景效果
11. **检查布局设置面板** — 确认主题切换选项已移除

### Phase 3 验证（P2 业务页面）

12. **打开巡检告警** — 确认搜索面板和告警列表深色适配
13. **打开巡检报告** — 确认报告详情页深色适配
14. **打开知识助手** — 确认聊天界面和会话列表深色适配
15. **打开系统监控 > 操作日志** — 确认 VxeTable 深色适配

## 回退方案

如果需要回退到原始样式：

```bash
git checkout main -- plus-ui/src/
```
